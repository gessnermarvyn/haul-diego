# Haul Diego

Customer-facing concept website for a San Diego junk-removal company. Vanilla HTML, CSS, and JavaScript — no build step. Open `index.html` or serve the folder with any static host (GitHub Pages from the `main` branch, site root).

## Pages

- `index.html` — home
- `quote.html` — rough-quote calculator (example prices only)
- `book.html` — pickup booking (demo, no backend)
- `snap.html` — Snap Haul photo quote (demo, no backend)
- `service-area.html` — San Diego County ZIP check

## Placeholders

Contact, reviews, some FAQ answers, legal links, the service-area map, and the hero illustration are clearly marked. Quote totals are example figures for the concept, not the owner's live rates.

Hero artwork in `img/hero.svg` is an original placeholder illustration, not a photograph of a real job.
